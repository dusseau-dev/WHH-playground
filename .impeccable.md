# Shannon Design Context

## Audience

Shannon is operated locally by security engineers and developers who are actively assessing a web application. They work in long, detail-heavy sessions and need to make high-consequence scope decisions quickly without losing sight of what the pipeline is doing.

## Primary Use Cases

- Configure a source-assisted or URL-only security assessment.
- Select security test categories, safe demonstration behavior, authentication, rules, and report filters.
- Start, monitor, cancel, and resume concurrent assessment pipelines.
- Triage confirmed, unvalidated, and ruled-out findings with their evidence.
- Read and download a final report without exposing target or provider secrets.
- Reuse assessment profiles while understanding whether credentials are persisted or session-only.

## Brand Personality

Forensic, exact, vigilant.

The interface should feel like a disciplined instrument used during an active investigation: dense but calm, unambiguous, and operational. It should not feel like a marketing site, a generic SaaS dashboard, a sci-fi terminal, or a playful developer toy.

## Visual Direction

- Near-black, subtly amber-tinted surfaces with Shannon amber used sparingly for identity and primary action.
- Distinct green, red, and blue semantics; every status also has text or an icon so color is never the only signal.
- Saira Condensed for headings and Atkinson Hyperlegible Next for body copy; tabular numerals for metrics and timing.
- Tight 4px spacing rhythm, square operational composition, and radii no larger than 6px.
- No gradients, glass effects, decorative glows, orbs, nested cards, colored side stripes, or oversized dashboard metrics.
- Existing `assets/shannon-banner.png` is the brand anchor.

## Interaction And Accessibility

- The usable operator workspace is the first screen; there is no landing page or onboarding tour.
- Meet WCAG 2.2 AA with semantic landmarks, visible focus, keyboard operation, 44px primary targets, live status regions, and non-color state cues.
- Honor reduced-motion preferences and provide explicit control over auto-following live activity.
- Keep all critical launch and lifecycle actions available at 390px width without overlap.
- Never display stored secrets. Show only present/missing and persistent/session-only states.
